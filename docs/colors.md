## Alpha Variants

Subtle backgrounds and overlays derived from semantic colors.

| Token | Description |
|-------|-------------|
| `--color-primary-alpha-8` | `rgb(from var(--color-primary) r g b / 0.08)` |
| `--color-primary-alpha-10` | `rgb(from var(--color-primary) r g b / 0.1)` |
| `--color-primary-alpha-15` | `rgb(from var(--color-primary) r g b / 0.15)` |
| `--color-success-alpha-10` | `rgb(from var(--color-success) r g b / 0.1)` |
| `--color-warning-alpha-10` | `rgb(from var(--color-warning) r g b / 0.1)` |
| `--color-error-alpha-10` | `rgb(from var(--color-error) r g b / 0.1)` |
| `--color-error-alpha-15` | `rgb(from var(--color-error) r g b / 0.15)` |
| `--color-info-alpha-10` | `rgb(from var(--color-info) r g b / 0.1)` |
| `--color-overlay` | `rgb(0 0 0 / 0.5)` |
| `--color-white-alpha-15` | `rgb(255 255 255 / 0.15)` |
